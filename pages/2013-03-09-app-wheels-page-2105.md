In essence most geometric chucks the output spindle on each stage of the chuck can be envisaged as a point rotating around the centre of the input spindle. This was described mathematically and investigated by F. A. Farris in his paper  “Wheels on Wheels on Wheels—Surprising Symmetry,” Mathematics Magazine 69(3), 1996 pp. 185–189.

<figure class="wp-recovered-caption">
<a href="{{ '/assets/recovered/23429894d1-Wheels.png' | relative_url }}"><img alt="Wheels" class="wp-image-2158" height="427" src="{{ '/assets/recovered/23429894d1-Wheels.png' | relative_url }}" width="535"/></a>
<figcaption>Each stage of a geometric chuck can be represented as a point rotating around the edge of a wheel</figcaption>
</figure>

This page of  my OTWB app allows you to explore paths generated in this way. Only a couple of predefined patterns are defined. Hopefully this will increase in future.

Each wheel is represented by two parameters
<ol>
<li>The Amplitude gives the radius of the wheel</li>
<li>The frequency gives the speed of rotation of the wheel and is relative to the speed of the first wheel. A negative value means it is rotating in the opposite direction to the first wheel.</li>
</ol>
So in the example above

<a href="{{ '/assets/recovered/d1a372e883-Wheel-example.png' | relative_url }}"><img alt="Wheel example" class="alignnone size-full wp-image-2159" height="136" src="{{ '/assets/recovered/d1a372e883-Wheel-example.png' | relative_url }}" width="139"/></a>
<ul>
<li>The first wheel has a radius of 50 and is rotating at 1 rev per minute.</li>
<li>The second wheel is half the size of the first but rotating at 7 times the speed in the same direction.</li>
<li>The third wheel is smaller than the second but rotating faster in the opposite direction. Its speed is 17 times that of the first wheel.</li>
</ul>
The path generated by this combination of wheels is displayed on the right in the view pane. You can select the number of points on the path and also the width of the path. All the values visible in the wheels data list can be changed thus allowing exploration of the shape of paths.

The user can choose to
<ul>
<li>Export the current path as a list of points</li>
<li>Export the current wheels pattern data to a file.</li>
<li>Import wheels pattern data and add to choices.</li>
<li>Navigate to the code generating page with the current path.</li>
<li>Add a new wheel (+)</li>
<li>Remove the last wheel  (-)</li>
<li>Change the grid size</li>
<li>View the points on the path</li>
</ul>
All these options are available on the bottom app bar.
