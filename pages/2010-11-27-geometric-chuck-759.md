The software on this page allows you to view patterns created by a Geometric Chuck with one or two stages.  This program was originally written for MSDOS by Bob Wade and has been updated to run under XP and above by myself.

<strong>Download the latest Windows version <a href=" http://www.ab48.uk/otblog/wp-content/uploads/2010/12/GeometricChuck.zip">here</a></strong> .

Extract the folder called GeometricChuck and simply run the setup.exe file . You need .Net version 3.5 installed on your computer. This software is still in development so contains bugs. Please let me know of any problems so I can fix them.

You can view some pre defined patterns as described by Thomas Bazley in his book <strong><em>Index to the Geometric Chuck</em></strong> and by Ross in his book <strong><em>Microcomputer Art</em></strong> simply by typing in an index value between 1 and 3500.

Alternatively you can create your own values and see the resulting pattern.
