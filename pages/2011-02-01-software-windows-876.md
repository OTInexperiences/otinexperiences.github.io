<h2>Requirements</h2>
Software - .Net version 4

Install - OTWB requires several folders to store its data. You need an area to store projects and also a library area used to save bits of things, such as Rosettes that you want to share across several projects.

As installed the program assumes the following folder structure.

<a href="/assets/placeholder-original-image.svg"><img alt="" class="alignnone size-medium wp-image-970" height="226" src="/assets/placeholder-original-image.svg" title="folder" width="300"/></a>

That is a root folder containing two sub folders called Library and Projects.

The Library folder itself contains several sub folders called Chucks, Headstocks,Rosettes,Surfaces and Gcode.

new OTWB Projects are stored in the Projects folder either all together in in individual folders. <a href="{{ '/assets/recovered/1cce1d681b-OTWB.zip' | relative_url }}">OTWB folder structure</a> Please just use the structure or change it to suit yourself. If you do change things dont forget to change the folder locations  by running the program and selecting My Project -&gt; settings -&gt;General -&gt; Folders in the  Project window.
