Currently the preferred display to use is the Quickview which is a two dimensional view looking down the Z axis. The full three dimensional view if chosen will probably crash the program. Also it is not capable of colour highlighting as Quickview does.  One of the problems was that the OpenGL toolkit I was using was undergoing rapid changes so I have tended not to concentrate on that aspect.  But I will return to it sooner or later. I tend to work using Quickview and then load the G code into emc and use its 3D based previewer to check the paths.
