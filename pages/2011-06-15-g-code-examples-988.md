Here are some examples of G code used to cut OT patterns. Some of these will be hand written G code and others will be subroutines generated by my software. Please feel free to use them. I use two different emc setups
<ol>
<li>The first uses XYBV axes

<figure class="wp-recovered-caption">
<a href="{{ '/assets/recovered/abc9a4a845-Directions-150x1501.png' | relative_url }}"><img alt="" class="aligncenter size-full wp-image-1706" height="150" src="{{ '/assets/recovered/abc9a4a845-Directions-150x1501.png' | relative_url }}" title="Directions-150x150" width="150"/></a>
<figcaption>XYBV axes</figcaption>
</figure>
<ol>
<li>the headstock moves transversely along the X axis. This is the direction the headstock would rock in a traditional rose engine.</li>
<li>the headstock moves along the Y axis. This is the direction that a traditional rose engine would have a pumping action.</li>
<li>the headstock rotates around the B axis.</li>
<li>the cutter moves along the V axis which is parallel to the Y axis. Thus the cutter moves perpendicular to the XY plane. This is equivalent to faceplate turning.</li>
</ol>
</li>
<li>The second uses XYBU where the XYB axes are as above
<ol>
<li>the U axis is parallel to the X axis so the cutter moves towards / away from the XY plane. Moving to the centre of rotation as in spindle turning.</li>
</ol>
</li>
</ol>
Please remember that All will have be written to work with a rotating axis machine. Not a standard mill unless you have a stepper driven rotating table.
