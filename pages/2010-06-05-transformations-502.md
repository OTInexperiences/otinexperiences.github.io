The transforms you can apply to a path are
<ol>
<li><strong>A scaling vector</strong> which is a collection of 3 positive numerical values. These values multiply the coordinate of a given dimension. So the first scale factor multiplies the x coordinate , the second the y and the third the z .  A scaling factor of 1.0 will leave the point unchanged, values between 0 and  0.99999...  will reduce the value whilst values greater than 1 will increase the value. Therefore a scaling vector of &lt;0.5,1,3&gt; will shrink the x value to half its size, do nothing to the y and make the z value three times bigger.</li>
</ol>

<ol>
<li><strong>A rotation</strong> through a given angle about a specified axis which may be either X or Y or Z. This has the same affect as the phase parameter in the rose engine simulation.</li>
</ol>
<p style="text-align: center;"></p>


<figure class="wp-recovered-caption">
<a href="/assets/placeholder-original-image.svg"><img alt="" class="size-full wp-image-558" height="303" src="/assets/placeholder-original-image.svg" title="transf1" width="313"/></a>
<figcaption>A hexagon after a rotation of 15 degrees</figcaption>
</figure>
<ol>
<li><strong>A translation</strong> will move the position of the centre of the path (always &lt;0,0,0&gt; when generated by the rose engine) to another point in space. Thereby offsetting the path so that it will no longer be located centrally on the workpiece.  The form is &lt;x,y,z&gt; so that  a translation of &lt;100,50,10&gt; will move the pattern horizontally 100mm to the right, 50mm vertically up and 10 mm in the depth direction. When specifying a translation you can use either standard Cartesian coordinates (&lt;x,y,z&gt; ) or Cylindrical coordinates which are &lt;radius,angle,depth&gt; values.</li>
</ol>
<p style="text-align: center;"></p>


<figure class="wp-recovered-caption">
<a href="/assets/placeholder-original-image.svg"><img alt="" class="size-full wp-image-559" height="293" src="/assets/placeholder-original-image.svg" title="transf2" width="353"/></a>
<figcaption>Hexagon after a translation along the x axis</figcaption>
</figure>
<ol>
<li>A <strong>Circular reflection</strong> will reflect a point through a circle of some radius. This does not alter the angle of the ray on which the point lies it only alters the distance of the point from the path centre.  Like an ordinary reflection the position of a point is transformed through the circle. So a point outside the circle will be transformed to be inside the circle and similarly a point inside the circle will be transformed to lie outside.  The depth value will be unchanged.  Let us assume that the circle we will reflect through has a radius of 200mm. A point on our path on a ray at 45 degrees with radius 150mm from the path centre &lt;150,45,d&gt; and thus inside the reflecting circle  will be transformed to &lt;250,45,d&gt; because the point was 50mm inside the circle it is transformed to be 50mm outside the circle.</li>
</ol>
<ol>
<li>A <strong>linear reflection</strong> using the 3D plane ax + by + cz = d  as the mirror.  For example a = 1, b=0,c=0  is a reflection in the vertical line x=d whilst if a=0,b=1,c=0 represents a reflection in the horizontal line y = d  and finally a=0,b=0,c=1  is a reflection in the line z=d.</li>
</ol>
Transformations may be composed together which means that more than one transformation may be applied to the same path.  So you might first scale, then rotate, then translate another path in order to create a new virtual path.
