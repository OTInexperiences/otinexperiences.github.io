A simple path is a sequence of vertices (three dimensional points) each vertex is represented by a set of coordinates. Each vertex is joined to the next by a straight line. You can specify vertices (points) in either Cartesian (XYZ) or Cylindrical (RAD) coordinates.  A path need not be closed but if it  is  then the last point on the path is connected back to the first.

The output prom the headstock of the rose simulator will generally be a simple path. The G-Code generator will output a simple linear move from one vertex to the next and when it reaches the last vertex back to the first if the path is closed.
Simple paths take up  memory space because each point is physically represented in memory.

As well as using the Rose simulator I have provided simple tools to create circular, polygonal and rectangular paths. Each of those elementary  paths doesn't actually require a list of vertices as they can be calculated as and when required. So all that is saved to disk is the data required to generate the vertices.   If you look at the main menu &gt; Tools you will see options to create these paths. each will present you with a dialog asking for the required data.
