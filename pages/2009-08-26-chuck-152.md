OTWB  allows you to use either a simple chuck or the equivalent (nearly) of a geometric chuck with multiple stages. Moreover each stage in the geometric chuck can be made to follow either a purely circular path or an elliptical path.

When using the chuck as a geometric chuck it is best to disable the spindle either by setting its type to NONE or by unticking all the axis control checkboxes.

The Angle parameter can be used to adjust the path of the chuck.

The Ratio parameter gives the speed ration between each stage and the previous stage.  There is no point of changing the ratio of a single stage chuck from 1.00.

It is the most sensitive factor in determining the actual path of the chuck centre.  If this parameter was set to 2 then the rate of rotation of the  stage would twice that of the previous stage in the same direction rotation. A parameter of -2 would set the rotation as twice that of the previous stage but in the opposite direction. You can also specify fractional values and   Because the chuck path is so sensitive to very small changes in the value of ratio between stages. I have added  a button to allow me to specify how much the ratio should change at each scroll of the spin button. Currently you can increment the ratio in steps of  0.001, 0.01, 0.1, 1 and 10.

Because you would not see the full path trace of a multi stage chuck in one single rotation you can use the turns button to specify how many rotations will be displayed. The plus button adds a stage to the chuck and the minus button removes the last stage.
