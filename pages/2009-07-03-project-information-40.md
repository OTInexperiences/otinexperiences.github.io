OTWB is project based. When you create a new project you need to specify its name. This name must be unique as it will be used to create a folder for the project in the projects folder. This folder will contain all the files relating to that project. For example the headstock information file  or A Lattice information file  or a surface file if one is specified or a collection of path files if they are automatically  saved when the program finishes.

All types of project have some common essential details which will be held in an information file in the project folder. This information is displayed in several tabs when you press the information button in the main page status bar. Project information is collected under several categories
<ul>
<li>General</li>
<li>Axes</li>
<li>Machining Data</li>
<li>Tool Box</li>
<li>Surface</li>
<li>Data</li>
<li>Display</li>
</ul>
Only one of the last two categories will be displayed depending on the project type.
<h3>General</h3>
<a href="/assets/placeholder-original-image.svg"><img alt="" class="size-full wp-image-384 alignnone" height="373" src="/assets/placeholder-original-image.svg" title="Screenshot-Project Information1" width="491"/></a>

This panel allows you to
<ul>
<li>change the project name.</li>
<li>Set the number of decimal places generated by the gcode this is the accuracy</li>
<li>Specify the type of gcode produced.</li>
<li>Specify if the original tool position is to be restored after a repeated execution.</li>
<li>If  Execute on Load set true then paths will automatically be generated as the program is loaded.</li>
<li>If Save paths is set true then all paths in the model will be saved as the program finishes and reloaded when the program is next started.</li>
<li>Set the toolpath grid angular and radial increment values.</li>
<li>Set the maximum radius of the grid.</li>
<li>Add some textual notes to describe the project.</li>
</ul>
<h3>Axes</h3>
<a href="/assets/placeholder-original-image.svg"><img alt="" class="size-full wp-image-385 alignnone" height="373" src="/assets/placeholder-original-image.svg" title="Screenshot-Project Information2" width="491"/></a>

This panel allows you to
<ul>
<li>Specify if a Rotary table is being used by the cnc system</li>
<li>Specify the rotation axis of the headstock. This will be Z for faceplate work and X for lathe work.</li>
<li>Specify the tool movement axis usually X in both cases above.</li>
<li>Specify the tool height direction. This is not changeable on my system but is included for completeness.</li>
<li>Specify the tool cutting direction called the depth direction. Again I anticipate this will be Z for both faceplate and lathe setups.</li>
<li>Specify the Axes to be used in the gcode.</li>
</ul>
<h3>Machining Data</h3>
<a href="/assets/placeholder-original-image.svg"><img alt="" class="size-full wp-image-386 alignnone" height="373" src="/assets/placeholder-original-image.svg" title="Screenshot-Project Information3" width="491"/></a>

This  panel allows you to
<ul>
<li>Specify the units used when generating gcode.</li>
<li>Specify the maximum depth of both roughing and finishing cuts. These values are used during gcode generation and determine the number of passes to be made.</li>
<li>Specify the feed rate and inverse feed rates. The feed rate is used for linear moves and the Inverse feed rate is used for angular moves when using a rotary table.</li>
<li>Specify the safe height. This is the depth the cnc cutter will move to when moving from one path to another.  Note that this can be negative but must be within the machine limits of your cnc system.</li>
<li>Specify the amount of cutter overlap to be used when machining a path that is wider than the cutter diameter being used and thus requiring several passes.</li>
<li>Specify if the depth is to be in the negative direction as is standard on CNC systems.</li>
</ul>
<h3>Tool Box</h3>
<a href="/assets/placeholder-original-image.svg"><img alt="" class="size-full wp-image-387 alignnone" height="373" src="/assets/placeholder-original-image.svg" title="Screenshot-Project Information4" width="491"/></a>

This panel allows you to add tools, giving their length and diameter. The currently selected tool is highlighted.
<h3>Surface</h3>
<a href="/assets/placeholder-original-image.svg"><img alt="" class="size-full wp-image-388 alignnone" height="373" src="/assets/placeholder-original-image.svg" title="Screenshot-Project Information5" width="491"/></a>

This panel allows you to specify the name of a surface file and if it is to be used in a project.  If the follow surface flag is set true then the toolpath display and the gcode generated will reflect this.
<h3>Data</h3>
<a href="/assets/placeholder-original-image.svg"><img alt="" class="size-full wp-image-389 alignnone" height="373" src="/assets/placeholder-original-image.svg" title="Screenshot-Project Information6" width="491"/></a>

This panel allows you to select the headstock file and the execution script file (** not yet implemented).  Also you can set the default values for radius and angle increment when creating a profile rosette. Use this option to also specify if by default paths are closed. And also you can set maximum and minimum limits for blending values.  Finally you can specify which lattices are part of the project.

Note ** that the Executor is not implemented. But when implemented is intended to be a text file that will act as a script to manage the process of generating paths and code.
<h3>Display</h3>

This panel lets you set the colours of various items shown in the graphical  displays.
