Sometime you may want to leave an area of your work undisturbed so that you can apply a pattern at a later stage, areas allow you do do that.
<h3>Types of area</h3>
An area may be designated as either a FILL or a MASK.

If the area is a FILL, then only the parts of paths lying within the area are displayed and used to  generate G code. All the rest of the path lying outside the area is ignored and may be snipped away.

<h3></h3>
<h3>Apply an area to a path</h3>
It is important to remember that Areas must be applied to paths, the masking effect does not occur naturally.

<a href="/assets/placeholder-original-image.svg"><img alt="" class="alignnone size-full wp-image-509" height="43" src="/assets/placeholder-original-image.svg" title="paths8" width="69"/></a>

The two buttons above are in the model explorer panel. If you click on the button on the right <a href="/assets/placeholder-original-image.svg"><img alt="" class="alignnone size-full wp-image-510" height="34" src="/assets/placeholder-original-image.svg" title="path9" width="32"/></a> then all areas that have their included flag set true will be applied to all paths that have their included flag set true.  Applying an area to a path results in the state of each vertex on the path possibly being changed.  If the area is a FILL then any vertex on the path lying within the area will have its state set as VISIBLE  and any vertex lying outside the area will have its state set as HIDDEN.  If the area boundary lies exactly on a vertex point (very unusual) that point will have its state labeled as either UP or DOWN nut normally two extra points will be created and added to the path for each area processed (unless the areas overlap).  If the path is entering an area the first boundary point will have its state set to UP if the area is a MASK and DOWN if the area is a FILL, similarly the point whee the path leaves the area will have its state set as DOWN if the area is a MASK and UP if the area is a FILL.

If more than one area is being applied to a path the state of each point will be either OR ed or AND ed with the standard state changes described above again depending on the area type.

The action attached to the left hand button <a href="/assets/placeholder-original-image.svg"><img alt="" class="alignnone size-full wp-image-517" height="34" src="/assets/placeholder-original-image.svg" title="area8" width="31"/></a> will remove all added boundary points and  reset the state of each vertex on the path to VISIBLE.
<h3>Area Boundaries</h3>
All areas have just one outer boundary but may have more than one inner boundaries. Each inner boundary represents a hole in the area.  Each boundary outer or inner may be any path except another area.

<h3>Creating Areas</h3>
One way of creating an area is to use the model explorer. First select the path you wish to use as the outer boundary then right click and choose Area -&gt; Create

<figure class="wp-recovered-caption">
<a href="/assets/placeholder-original-image.svg"><img alt="" class="size-full wp-image-512" height="315" src="/assets/placeholder-original-image.svg" title="araea2" width="568"/></a>
<figcaption>Create an area using a selected path</figcaption>
</figure>

You can select more than one path. In that case the first path is taken as the outer boundary and all the remaining paths are assumed to be inner boundaries.

However once an area has been created you can add further inner boundaries to it. First select the area and right click, then choose Area&gt; Add inner boundary. You will be presented with a list of available paths to select from.

You can also use the right click menu to change the area from a FILL to a MASK or vice versa.
<h3>Removing an inner boundary</h3>
<figure class="wp-recovered-caption">
<a href="/assets/placeholder-original-image.svg"><img alt="" class="size-full wp-image-514" height="291" src="/assets/placeholder-original-image.svg" title="area4" width="389"/></a>
<figcaption>Removing an inner boundary</figcaption>
</figure>

In the example above we wish to remove Path_2_Ref from the area.  Click the &gt; button next to your area (called Area above ) to expand the tree  and see the list of boundaries. Now choose a boundary here Path_2_Ref and delete just as an ordinary path.  Note that this will only remove the selected path from the area. The actual path itself will still be stored in the model and can be used again.
<h3>Other ways of creating an area</h3>
I have added three buttons to the model explorer panel and to the Tools sub menu on the main menu  to create some common areas.
<ul>
<li>a circular annulus ,</li>
<li>a rectangle</li>
<li>a polygon</li>
</ul>
Choosing one of these options you will be presented with a dialog asking for various parameters, once completed the area will be created and added to the model. But again remember that any path can be used excluding other areas of course.

<em> </em>

Finally notice that you are allowed to specify in the project info the colors to be used when displaying areas<em> </em>so that you can distinguish between a MASK and a FILL.
