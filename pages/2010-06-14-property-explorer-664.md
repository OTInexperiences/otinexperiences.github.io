The property explorer allows you to view and edit values from items selected in various panels. For example select a path in the model explorer and the property explorer displays all relevant information about that path.

<a href="/assets/placeholder-original-image.svg"><img alt="" class="aligncenter size-full wp-image-668" height="1012" src="/assets/placeholder-original-image.svg" title="propexp1" width="768"/></a>

All properties highlighted in red are not editable but all those in black are. So you could change the width of Path_3 above  by clicking on the width value, or you could change the transforms scale factors etc.

If you select a rosette in the headstock display you can use the property explorer to alter the various rosette parameters.
