Some time you may want to cut a helix along a piece that is not cylindrical. If you can record the profile of the piece as a sequence of values then you can use these to adjust the position of the headstock and thus  of the piece as you cut. In my case I can move the headstock along the X axis as the helix is cut along the Y axis.  For example let us assume that our  X axis reference line  is set at some convenient X value to say 100mm. Then at each y position along the piece  the radius value will be either greater or smaller than at our reference point.

<a href="{{ '/assets/recovered/535cd94aa8-profile1.png' | relative_url }}"><img alt="" class="aligncenter size-medium wp-image-1010" height="388" src="{{ '/assets/recovered/80c73d319d-profile1-243x300.png' | relative_url }}" title="profile1" width="314"/></a>In the image above all radii on our workpiece will be less than the radius represented by the reference line. Now imagine our cutting tool is placed on the reference line. In order to cut larger radial values we must move the spindle centre away from the tool and for smaller radial values we must move the spindle centre towards our tool. Which in my case means changing the X position of the headstock.

These values used to offset the headstock spindle may be stored in the EMC variables available to the user (from #31 to #5000) and used in your programs. You can load values into these variables by defining a subroutine such as the one below.
<pre>(profile data is held in the following structure)
( profile start value is  in   #1000 )
( profile increment value is  in   #1001 )
( profile end value is in     #1002 )
( profile size is in    #1003 )

o&lt;profile2&gt; sub  (establish profile values )
#1000 = 0        (start at y = 0)
#1001 = -10      (increment in 10mm steps )
#1002 = -100     (end at -100 mm )
#1003 = 11    (11 values )

(now we follow with actual profile values)
(choose linear example - autogenerated usually)
#1004 = 0    ( y = 0)
#1005 = 5    ( y = -10 )
#1006 = 10    ( y = -20 )
#1007 = 15    ( y = -30 )
#1008 = 20    ( y = -40 )
#1009 = 25    ( y = -50 )
#1010 = 30    ( y = -60 )
#1011 = 35    ( y = -70 )
#1012 = 40    ( y = -80 )
#1013 = 45    ( y = -90 )
#1014 = 50    ( y = -100 )

o&lt;profile2&gt; endsub
M2</pre>
Saving this code in a file called profile2.ngc in the emc program prefix folder allows you to execute the subroutine including the line below in your program
<pre>o&lt;profile2&gt; call  (load profile)</pre>
My code assumes that the profile is defined by a collection of equally spaced sample points. To get the offset for a point between the samples we can use linear interpolation.  Then the profile is actually represented as a sequence of straight line segments joining each sample position.  You can get quite accurate approximations by decreasing the distance between samples.

Once loaded you then need some functions to return the correct offset value for a given position along the helix axis. I have written a few gcode subroutines to help with this.
<pre>(Interpolate between two values returns interpolated value in #&lt;_result&gt; )
( the first value must be less than the second value)
(parameters #1 = value 1)
(        #2 = fraction )
(        #3 = value 2 )
( returns value in global #&lt;_result&gt; )
o&lt;linterp&gt; sub
 #&lt;_result&gt; = [ #1 * [ 1 - #2 ] + [#3 * #2 ]]
o&lt;linterp&gt; endsub

(get the profile value at position given by param #1 )
(assumption is that value is in the profile range user must check this first)
(uses other param values as local variables )
o&lt;profile_value&gt; sub
     #2 = [[#1 - #1000] / #1001]  (find how many increments we are from start of profile)
     #3 = [fix [#2] ]  (integer value of increments )
     #4 = [#2 - #3]      (fractional difference )

     o&lt;if_needs_interp&gt; if [[ABS [#4]] GT 0 ]
         o&lt;linterp&gt; call [#[1004 + #3]]  [#4] [#[1005 + #3]]
     o&lt;if_needs_interp&gt; else
         #&lt;_result&gt; = [#[1004 + #3]]
     o&lt;if_needs_interp&gt; endif
o&lt;profile_value&gt; endsub</pre>
Now simply include a call to profile_value to get the offset and add it to our X value accordingly.  If you are using Incremental Distance Mode then add the difference between the current and previous offsets instead.

The full program code to produce this path is
<pre>(Author Alan Battersby)
(Program to cut a helix along the -Y axis as given by my machine setup on a given profile)

(Comment - Note this is not for a standard Mill. )
(In my setup the cutter depth axis U )
(Also the helix rotates around the Y axis, here I use B The x value remains constant)

(set some global values )
G21 G40 G49 G54 G80 G90 G94
#&lt;_safeheight&gt; = 5
(return value is at location #31 )
#&lt;_result&gt; = #31
o&lt;profile2&gt; call  (load profile)

(Interpolate between two values returns interpolated value in #&lt;_result&gt; )
( the first value must be less than the second value)
(parameters #1 = value 1)
(        #2 = fraction )
(        #3 = value 2 )
( returns value in global #&lt;_result&gt; )
o&lt;linterp&gt; sub
 (debug linterp #1 #2 #3 )
 #&lt;_result&gt; = [ #1 * [ 1 - #2 ] + [#3 * #2 ]]
o&lt;linterp&gt; endsub

(get the profile value at position given by param #1 )
(assumption is that value is in the profile range user must check this first)
(uses other param values as local variables )
o&lt;profile_value&gt; sub
 #2 = [[#1 - #1000] / #1001]  (find how many increments we are from start of profile)
 #3 = [fix [#2] ]  (integer value of increments ) �
 #4 = [#2 - #3]      (fractional difference )
 o&lt;if_needs_interp&gt; if [[ABS [#4]] GT 0 ]
 o&lt;linterp&gt; call [#[1004 + #3]]  [#4] [#[1005 + #3]]
 o&lt;if_needs_interp&gt; else
 #&lt;_result&gt; = [#[1004 + #3]]
 o&lt;if_needs_interp&gt; endif
o&lt;profile_value&gt; endsub

o&lt;helix&gt; sub
 #&lt;pitch&gt;    = #1  (pitch of helix )
 #&lt;length&gt;     = #2  (length of helix to cut - width of cutter)
 #&lt;step&gt;       = #3  (angular step )
 #&lt;depth&gt;     = #4  (depth to cut )
 #&lt;cur_length&gt;    = #5 (local)
 #&lt;cur_prof&gt;    = #6 (local)
 #&lt;last_prof&gt;    = #7 (local)

 (first caluculate some required values for local variables)
 #&lt;max_angle&gt; = [ 360 * [#&lt;length&gt; / #&lt;pitch&gt;]]
 #&lt;k&gt; = [#&lt;pitch&gt; / 360] ( helix k factor )
 #&lt;angle&gt; = 0        (initial starting angle)
 #&lt;last_prof&gt; = 0    (starting so no previous profile value)

 (start by moving absolutely to cut depth )
 g90 g1 u [#&lt;depth&gt;]
 (loop through angles until max angle reached )
 g91
 o&lt;loop&gt; while [#&lt;angle&gt; LT #&lt;max_angle&gt;]
 #&lt;cur_length&gt; = [#&lt;k&gt; * #&lt;angle&gt;]
 o&lt;profile_value&gt; call [#&lt;cur_length&gt;]
 #&lt;cur_prof&gt; = [#&lt;_result&gt;]
 g1 y[#&lt;k&gt; * #&lt;step&gt; ]  b[#&lt;step&gt;] x[#&lt;cur_prof&gt; - #&lt;last_prof&gt;]
 #&lt;angle&gt; = [[#&lt;angle&gt;] + [#&lt;step&gt;]]
 #&lt;last_prof&gt; = [#&lt;cur_prof&gt;]
 o&lt;loop&gt; endwhile
 g90 g0 u[#&lt;_safeheight&gt;] (move cutter absolutely to safe height)
o&lt;helix&gt; endsub

(************ main program ************)
( set initial values to suit your own application)
#&lt;_feedrate&gt;    = 40    (your value for feed rate)
#&lt;_pitch&gt;    = -25      (this value is the helix pitch )
#&lt;_length&gt;    = -100     (this value is the length of the helix )
#&lt;_step&gt;    = 1    (this is the angular step in degrees )
#&lt;_maxdepth&gt;    = -1     (depth of helix )
#&lt;_depthinc&gt;    = -1    (depth increment for each pass )
#&lt;_numhelices&gt;    = 1    (number of helix starts )
#&lt;_profile_x&gt;   = 0

#&lt;_result&gt; = 0
(my setup assuming that values x,y,u,b are all zero when starting)

#&lt;start_angle_inc&gt; = [360 / #&lt;_numhelices&gt;]
#&lt;curr_helix&gt; = 0;

(code cuts full depth of each helix before moving on to the next)
o&lt;helix_loop&gt; while [#&lt;curr_helix&gt; LT #&lt;_numhelices&gt;]
 #&lt;curr_depth&gt; = [#&lt;_depthinc&gt;]
 o&lt;depth_loop&gt; while [#&lt;curr_depth&gt; GE #&lt;_maxdepth&gt;]
   g90 g0 u[#&lt;_safeheight&gt;] f[#&lt;_feedrate&gt;]
   g90 g0 x0 y0
   g90 g0 b[#&lt;curr_helix&gt; * #&lt;start_angle_inc&gt;] f[#&lt;_feedrate&gt;]  (set initial position)
   o&lt;helix&gt; call [#&lt;_pitch&gt;] [#&lt;_length&gt;] [#&lt;_step&gt;] [#&lt;curr_depth&gt;]
   #&lt;curr_depth&gt; = [[#&lt;curr_depth&gt;] + [#&lt;_depthinc&gt;]]
 o&lt;depth_loop&gt; endwhile
 #&lt;curr_helix&gt; = [[#&lt;curr_helix&gt;] + 1]
o&lt;helix_loop&gt; endwhile
M2 (end program)</pre>
