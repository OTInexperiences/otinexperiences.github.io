This page is slightly different from the others. Because the rosettes on a rose engine barrel act to offset the headstock from its central position. The values generated by this page are also offsets and not absolute positions.

Therefore the path generated by a tool is dependent on the tools position as well as the arrangement  of rosettes on the barrel and finally the overall phase of the barrel.

At the bottom of the display there is a slider to allow you to change the position of the tool relative to the headstock set central position. At the side of the display is another slider to allow you to set the overall phasing of the barrel.

<h2> The Barrel</h2>
Comprises of one or more rosettes. These rosettes are displayed in the scrollable view to the side of this display. Again like the other pages the rosette parameters can be adjusted and the display is updated to reflect the changed path.

There are buttons on the bottom app bar that allow you to
<ol>
<li>Export the path</li>
<li>Export the barrel data</li>
<li>Import a barrel</li>
<li>Create a new empty barrel which is then automatically selected.</li>
<li>Clear the currently selected barrel this means remove all its rosettes.</li>
<li>Add a rosette (+)</li>
<li>Remove a rosette (-)</li>
<li>Change the grid size</li>
<li>View the points on the path.</li>
</ol>

<h2>Rosettes</h2>
You can choose between
<h2>An Elliptical/Circular Rosette</h2>
There are 3 parameters

<a href="{{ '/assets/recovered/efafe2de70-Elliptical-Rosette.png' | relative_url }}"><img alt="Elliptical Rosette" class="wp-image-2123 alignnone" height="134" src="{{ '/assets/recovered/b71a9e09c7-Elliptical-Rosette-150x134.png' | relative_url }}" width="150"/></a>
<ul>
<ul>
<li>Eccentricity - this is the ratio between the two radii. A value of 1 gives a circle a value less than 1 gives an ellipse whose thickness depends on the value. So a value of 0.5 will result in an ellipse whose vertical thickness is half its width</li>
<li>Weight this is a multiplying factor that gives the size of the ellipse. The standard ellipse is 1 unit wide so set the weight to 20 to get one 20 units wide.</li>
<li>Phase this determines the rotation of the ellipse around its centre.</li>
</ul>
</ul>
<h2>A sine wave rosette</h2>
Again three parameters

<a href="{{ '/assets/recovered/93e3b1f9ae-sinwave-Rosette.png' | relative_url }}"><img alt="sinwave Rosette" class="size-full wp-image-2124 alignleft" height="139" src="{{ '/assets/recovered/93e3b1f9ae-sinwave-Rosette.png' | relative_url }}" width="149"/></a>

<li>Frequency - this gives the number of waves</li>
<li>Weight  - this gives the height of a wave</li>
<li>Phase - the rotation around its centre</li>
</ul>

<h2>Gear Rosette</h2>
<a href="{{ '/assets/recovered/94d7973847-gear-rosette.png' | relative_url }}"><img alt="gear rosette" class="alignnone size-full wp-image-2128" height="131" src="{{ '/assets/recovered/94d7973847-gear-rosette.png' | relative_url }}" width="148"/></a>

This is still very experimental and the code is not quite correct. It produces the outline of a spur gear. Which depends upon the following parameters

<figure class="wp-recovered-caption">
<a href="{{ '/assets/recovered/ca396b8c24-gear-1.png' | relative_url }}"><img alt="parameters" class="size-full wp-image-2145" height="301" src="{{ '/assets/recovered/ca396b8c24-gear-1.png' | relative_url }}" width="345"/></a>
<figcaption>parameters</figcaption>
</figure>
<ul>
<li>The number of teeth in the gear</li>
<li>The module value</li>
<li>The pressure angle</li>
<li>The weight has no effect at present as the diameter of the gear is solely dependent on the previous parameters.</li>
<li>Phase</li>
<li>Undercut - currently a fudge factor to get something like the correct tooth shape.</li>
</ul>
<figure class="wp-recovered-caption">
<a href="{{ '/assets/recovered/f9ffc2650c-gear-2.png' | relative_url }}"><img alt="gear 2" class="size-thumbnail wp-image-2146" height="150" src="{{ '/assets/recovered/736bf3121b-gear-2-150x150.png' | relative_url }}" width="150"/></a>

Remember that with all these rosettes a negative tool position simply means that on a real mechanical rose engine the tool is set to the opposite side of the barrel than the rubber.

When you add several rosettes to a barrel, the path traced is the combined outline of these rosettes.
