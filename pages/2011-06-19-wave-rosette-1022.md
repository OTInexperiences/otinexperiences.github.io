A common way of generating patterns for OT is to use a rosette whose outline is a sine wave.

<a href="{{ '/assets/recovered/19b0576222-wave1.png' | relative_url }}"><img alt="" class="aligncenter size-medium wp-image-1023" height="299" src="{{ '/assets/recovered/ea255ce76d-wave1-300x299.png' | relative_url }}" title="wave1" width="300"/></a>

A subroutine to calculate the height of a wave for a given angle is shown below.  As with the other examples the value is returned in a global variable called _result.
<pre>(sub to generate a wave pattern around the spindle axis)
(returns its result in global #&lt;_result&gt; )
( formula is )
( amp = Amplitude * Sin[angle - phase]  )
( result = Radius + [[absolute] ? Math.Abs[amp] : amp]] )
o&lt;wave_rosette&gt; sub
     #&lt;angle&gt;      = #1
     #&lt;amplitude&gt;  = #2
     #&lt;frequency&gt;  = #3
     #&lt;phase&gt;      = #4
     #&lt;absolute&gt;   = #5

     #&lt;_result&gt; = [#&lt;amplitude&gt; * sin[#&lt;frequency&gt; * [ #&lt;angle&gt; - #&lt;phase&gt;]]]
     o&lt;if1&gt; if [#&lt;absolute&gt; GT 0]
         #&lt;_result&gt; = abs[#&lt;_result&gt;]
     o&lt;if1&gt;  endif
o&lt;wave_rosette&gt; endsub</pre>
The  height of the wave at a given angle depends upon:
<ol>
<li>the amplitude which is the maximum height of the wave</li>
<li>the frequency which determines the number of bumps in the wave</li>
<li>the phase which determines the rotation of the wave</li>
<li>a flag to determine if it is a true wave (that is has heights both above and below zero) or is a rectified wave where all heights are positive.</li>
</ol>
First set cutter to starting position then call the subroutine in a loop as illustrated below
<pre>(************ main program *********)
#&lt;_maxdepth&gt;    = -5     (depth of cut )
#&lt;_depthinc&gt;    = -2    (depth increment for each pass )
#&lt;last_x&gt;    = 0    (last x value )

#&lt;_curr_depth&gt; = [#&lt;_depthinc&gt;]

o&lt;depth_loop&gt; while [#&lt;_curr_depth&gt; GE #&lt;_maxdepth&gt;]
 g90 g0 X50  b0 (will cut on 100 mm diameter circle)
 g90 g0 V[#&lt;_curr_depth&gt;] (depth)
 #&lt;angle&gt; = 0
 o&lt;angle_loop&gt; while [#&lt;angle&gt; LE 360]
     o&lt;wave_rosette&gt; call [#&lt;angle&gt;] [10] [6] [0] [0]
     g91 g1 x[#&lt;_result&gt; - #&lt;last_x&gt;] b1 f[#&lt;_feedrate&gt;]
     #&lt;angle&gt; = [1 + #&lt;angle&gt;]
     #&lt;last_x&gt; = #&lt;_result&gt;
 o&lt;angle_loop&gt; endwhile
 #&lt;_curr_depth&gt; = [[#&lt;_curr_depth&gt;] + [#&lt;_depthinc&gt;]]
o&lt;depth_loop&gt; endwhile
M2</pre>

The full code for a test program is
<pre>(Example of a rosette pattern)

(set some global values )
G21 G40 G49 G54 G80 G90 G94
#&lt;_safeheight&gt;     = 5
#&lt;_feedrate&gt;     = 50
#&lt;_result&gt;     = #31

(sub to generate a wave pattern around the spindle axis)
(returns its result in global #&lt;_result&gt; )
( formula is )
( amp = Amplitude * Sin[angle - phase]  )
( result = Radius + [[absolute] ? Math.Abs[amp] : amp]] )
o&lt;wave_rosette&gt; sub
 #&lt;angle&gt;    = #1
 #&lt;amplitude&gt;    = #2
 #&lt;frequency&gt;    = #3
 #&lt;phase&gt;    = #4
 #&lt;absolute&gt;    = #5

 #&lt;_result&gt; = [#&lt;amplitude&gt; * sin[#&lt;frequency&gt; * [ #&lt;angle&gt; - #&lt;phase&gt;]]]
 o&lt;if1&gt; if [#&lt;absolute&gt; GT 0]
 #&lt;_result&gt; = abs[#&lt;_result&gt;]
 o&lt;if1&gt;  endif
o&lt;wave_rosette&gt; endsub

(************ main program *********)
#&lt;_maxdepth&gt;    = -5     (depth of helix )
#&lt;_depthinc&gt;    = -2    (depth increment for each pass )
#&lt;last_x&gt;    = 0    (last x value )

#&lt;_curr_depth&gt; = [#&lt;_depthinc&gt;]

o&lt;depth_loop&gt; while [#&lt;_curr_depth&gt; GE #&lt;_maxdepth&gt;]
 g90 g0 X50  b0 (will cut on 100 mm diameter circle)
 g90 g0 V[#&lt;_curr_depth&gt;] (depth)
 #&lt;angle&gt; = 0
 o&lt;angle_loop&gt; while [#&lt;angle&gt; LE 360]
 o&lt;wave_rosette&gt; call [#&lt;angle&gt;] [10] [6] [0] [0]
 g91 g1 x[#&lt;_result&gt; - #&lt;last_x&gt;] b1 f[#&lt;_feedrate&gt;]
 #&lt;angle&gt; = [1 + #&lt;angle&gt;]
 #&lt;last_x&gt; = #&lt;_result&gt;
 o&lt;angle_loop&gt; endwhile
 #&lt;_curr_depth&gt; = [[#&lt;_curr_depth&gt;] + [#&lt;_depthinc&gt;]]
 g90 go V[#&lt;_safeheight&gt;] (go back to safe height)
o&lt;depth_loop&gt; endwhile
M2</pre>
