There are various helper subroutines defined to help with the creation of Rosettes and adding them to a spindle. The addresses of the two spindles are held in the two named global variables <strong>#&lt;_MainSpindle&gt;</strong> and<strong> #&lt;_PumpSpindle&gt;</strong>

There is a subroutine called<strong><em> Create&lt;RosetteName&gt;Rosette</em></strong> for each type of rosette and it is used to create the data for a rosette in the rosette data area and returns that rosettes address  in the global variable<strong> #&lt;_result&gt;</strong> but does <strong><span style="text-decoration: underline;">not</span></strong> add that rosette to any spindle.

To add a rosette to a spindle use the <strong>AddToSpindle</strong> [] []  subroutine.
<pre>(---------- first code to create various types of Rosette --------------)
o&lt;CreateEllipticalRosette&gt; sub    (#1 is the Major radius     )
                                  (#2 is the Minor radius     )
                                  (#3 is the phase            )
                                  (#4 is the blending value   )</pre>
This subroutine when called will create an elliptical rosette and return is address in the global variable #&lt;_result&gt;

So when the following gcode program lines are executed
<pre>o&lt;CreateEllipticalRosette&gt; call [100] [50] [45] [1]
o&lt;AddRosetteToSpindle&gt; call [#&lt;_MainSpindle&gt;] [#&lt;_result&gt;]</pre>
The first subroutine call will create an ellipse whose major radius = 100, minor radius = 50, phase angle = 45 and blend value = 1. Then the second will add that rosettes address to the main spindle (automatically incrementing the spindle count along the way)

Similarily
<pre>o&lt;CreateWaveRosette&gt; sub    (#1 is the Radius        )
                            (#2 is the Frequency     )
                            (#3 is the Amplitude     )
                            (#4 is the Phase         )
                            (#5 is the abs flag      )
                            (#6 is the blend flag    )</pre>
and the lines
<pre>o&lt;CreateWaveRosette&gt; call [100] [6] [25] [0] [1] [1]
o&lt;AddRosetteToSpindle&gt; call [#&lt;_PumpSpindle&gt;] [#&lt;_result&gt;]</pre>
will create a wave rosette with radius = 100, frequency = 6, amplitude = 25 , phase = 0, with the absolute flag set true, abs=1 and blend value = 1 and then add that rosette to the pumping spindle.

All rosettes have a Create... Rosette subroutine
<pre>o&lt;CreatePolyRosette&gt; sub   (#1 is the Major Radius           )
                           (#2 is the Minor radius for star  )
                           (#3 is the Number of sides        )
                           (#4 is the Phase                  )
                           (#5 is the star flag              )
                           (#6 is the blend flag             )

o&lt;CreateEpiRosette&gt; sub    (#1 is the Major Radius             )
                           (#2 is the Minor radius for circle  )
                           (#3 is the Phase                    )
                           (#4 is the Blend                    )

o&lt;CreateHypoRosette&gt; sub   (#1 is the Major Radius     )
                           (#2 is the Minor radius     )
                           (#3 is the Phase            )
                           (#4 is the blend flag       )

o&lt;CreateSpiralRosette&gt; sub    ( r = a + b * angle        )
                           (param #1 is a                )
                           (param #2 is b                )
                           (param #3 is the Phase        )
                           (param #4 is the Blend        )</pre>
<pre>o&lt;CreatePetalRosette&gt; sub  (#1 is the Major Radius           )
                           (#2 is the Minor radius for star  )
                           (#3 is the Number of sides        )
                           (#4 is the Phase                  )
                           (#5 is the blend flag             )</pre>
After the rosettes have been created and added to the spindles, the path can be generated witha call to thefollowing subroutine
<pre>o&lt;Generate_Path&gt; sub
            (param #1 is start angle              )
            (param #2 in angle increment          )
            (param #3 is end angle                )
            (param #4 is feedrate                 )
            (param #5 is tool offset              )
            (param #6 is the depth to cut at      )
            (param #7 is phase of main spindle    )
            (param #8 is phase of pump spindle    )</pre>
The value of the fifth parameter #5  is used with the Generate_path subroutine to allow the user to vary the size of the paths generated.  So
<pre>#&lt;_ToolOffset&gt; = 0
o&lt;Generate_Path&gt; call [0] [1] [360] [60][#&lt;_ToolOffset&gt;] [-2] [0] [0]
#&lt;_ToolOffset&gt; = 10
o&lt;Generate_Path&gt; call [0] [1] [360] [60][#&lt;_ToolOffset&gt;] [-2] [0] [0]</pre>
will result is two paths being cut one inside the other with the outer path separated from the inner one by 10 length units
<h2>Typical main program</h2>
Please note that for simple illustrative purposes no depth information is included here
<pre>(---------------------- Start of main program --------------------------)

#&lt;_UseRotary&gt;        = 1    ( we are using a rotary machine  )
#&lt;_UseMainSpindle&gt;   = 1    ( we are using main spindle      )
#&lt;_UsePumpSpindle&gt;   = 0    ( not using pump                 )
#&lt;_UseChuck&gt;         = 0    ( not using a chuck              )
#&lt;_UseBlending&gt;      = 0    ( not blending rosettes          )
#&lt;_ToolOffset&gt;       = 0    ( tool at centre of work         )
#&lt;_Safeheight&gt;       = 2    ( Safe height                    )

( now must add at least one rosette to the spindle           )
##&lt;_MainSpindle&gt; = 0        ( ensure spindle is empty        )
##&lt;_PumpSpindle&gt; = 0

o&lt;CreateWaveRosette&gt; call [100] [6] [25] [0] [1] [1]
&lt;AddRosetteToSpindle&gt; call [#&lt;_MainSpindle&gt;] [#&lt;_result&gt;]

o&lt;CreateWaveRosette&gt; call [80] [8] [25] [20] [0] [-0.2]
o&lt;AddRosetteToSpindle&gt; call [#&lt;_MainSpindle&gt;] [#&lt;_result&gt;]

o&lt;CreateWaveRosette&gt; call [0] [12] [30] [0] [0] [1] (r, freq,apl,phase,abs,blend)
o&lt;AddRosetteToSpindle&gt; call [#&lt;_PumpSpindle&gt;] [#&lt;_result&gt;]

g90 g0 x100
o&lt;Generate_Path&gt; call [0] [1] [10 * 360] [60] [#&lt;_ToolOffset&gt;] [0] [0]
M2  (End of program)</pre>
