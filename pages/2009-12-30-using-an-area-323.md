The screen shot below shows four paths and an area. The paths were made by taking a simple circular path and first scaling it by 0.5 in the y direction leaving x and z unchanged. Three further virtual copies of this path were made each having a different rotational angle.

<figure class="wp-recovered-caption">
<img alt="Paths before mask applied" class="size-full wp-image-327" height="498" src="/assets/placeholder-original-image.svg" title="maskexample1" width="697"/>
<figcaption>Paths before mask applied</figcaption>
</figure>

Clicking the run button in the path explorer will cause the software to apply any included areas to all the included paths. The result is shown graphically in the quick-view. All masked portions of the path are hidden and the points where a path enters and leaves a mask are highlighted in red.

<figure class="wp-recovered-caption">
<img alt="View after masks have been applied" class="size-full wp-image-329" height="465" src="/assets/placeholder-original-image.svg" title="maskexample2" width="650"/>
<figcaption>View after masks have been applied</figcaption>
</figure>

At the point where the path enters a mask Gcode generation will produce code that moves the cutter up to the defined safe height . The cutter will then be moved to the point where the path exits the mask and it will then feed down to the current cutting depth.

<a href="/assets/placeholder-original-image.svg"><img alt="" class="alignnone size-medium wp-image-348" height="225" src="/assets/placeholder-original-image.svg" title="gcode_mask" width="300"/></a>
