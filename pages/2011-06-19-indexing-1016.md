One of the commonest forms of tasks is Indexing, that is moving to a given angular position before doing a task such as drilling a hole or plunging a cutter etc. This task is easily written in g code especially when using a rotary machine. To move to the next index position we simply program the assigned rotary axis with a relative move through a given angle. This angle is simply the angle range we wish to index over divided by the number of index positions.  A simple gcode subroutine is shown below
<pre>(subroutine to move to the next index position at safe height)
(and perform a task )
(params are     #1 = number of index points )
(        #2 = start angle in degrees )
(        #3 = end angle in degrees )

o&lt;circular_indexer&gt; sub
 #5 = [[#3 - #2] / #1]       ( angle to move for each index position )

g90 g0 W[#&lt;_safeheight&gt;]    ( move too post to safe height )
g90 g0 C[#2]                      ( rotate to start position )
o&lt;indx_loop&gt; repeat [#1]
o&lt;dotask&gt; call [-70]
 g90 g0 W[#&lt;_safeheight&gt;] (move up before move to next position)
 g91 g0 C[#5]          (move to next increment position)
o&lt;indx_loop&gt; endrepeat

o&lt;circular_indexer&gt; endsub</pre>
And an example of its use is shown below
<pre>(************ main program *********)
g90 g0 W[#&lt;_safeheight&gt;]
g0 X50  (will index on 100 mm diameter circle)
o call [12] [0] [360]
M2</pre>
I deliberately placed the action to be performed at the index position in its own subroutine so that it could be made as simple or as complex as required.  For eaxmple we could cut flutes in a column by making the subroutine something like the one below.
<pre>(This is the task to perform at each indexed position)
(Remember when this task is called we are at safe height)
(This task cuts a flute by making a single straight line cut )
(parameter #1 is the length of the cut )
o&lt;dotask&gt; sub
 g90 g0 Z0
 g91 g1 Z [#1] f[#&lt;_feedrate&gt;]
o&lt;dotask&gt; endsub</pre>
