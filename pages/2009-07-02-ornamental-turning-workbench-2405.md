The software that I am currently writing allows me to design a specific type of  pattern (those generated by Rose engines) and then generate the <a href="http://en.wikipedia.org/wiki/Gcode" target="_blank">gcode</a> to create it  using emc.

I am developing my software using <a href="http://www.mono-project.com/Main_Page" target="_blank">Mono</a> running on openSUSE 11.2 Linux.  It will run on Ubuntu 8.10 which is the version of Linux used by emc.  I would rather develop my software on the same Linux system that runs emc but Mono on Ubuntu is not quite as up to date as on openSuse and thus program development is easier on openSUSE. For anyone interested I am using <a href="http://monodevelop.com/" target="_blank">MonoDevelop</a> as the IDE a piece of software I highly recommend. Incidentally Mono will run on windows so I am hoping my software will run on XP etc but again I have still to try this.  When I have completed the main development I will spend time ensuring it runs at least on Ubuntu and possibly XP.

In its present version my software is  <a href=" " target="_self">project</a> based.  The user is able to generate paths based either on
<ol>
<li>A Simulation of a <a href=" {{ '/rose-engine-project/' | relative_url }}" target="_self">Rose Engine</a> .</li>
<li>A helper for generating <a href=" {{ '/software/ornamental-turning-workbench/lattice-designs/' | relative_url }}" target="_self">Lattice designs</a> (currently not implemented)</li>
</ol>
Generally there are two stages to producing a the gcode for a particular design. First you must create the 3D paths you want the cutter to follow. Then produce gcode from these paths.

The main window of  the general view of my software shown below contains several dockable windows. The main window shown is a two dimensional colour coded display showing the paths defined so far.

The project here is based on the Rose Engine. And is displaying 3 Hypocycloidal paths.

The left hand pane displays a explorer that allows you to view the points generated along each path. You cannot edit the points but the pane does allow you to exclude or include a particular path in the view and subsequent gcode generation.
