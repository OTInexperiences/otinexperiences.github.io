If you want to cut a path on a non flat surface you can define such a surface and add it to your project.  You can then opt to allow any paths to follow this surface.  Surfaces are created as either rectangular or rotational and are defined using  a set of profiles.  In a rectangular surface each profile defines the depth (z) against length (x)  for a specific width (y) value. In a rotational surface each profile defines the depth (z) against radius (r) for a specific angle (a) value. For a rotational surface with a single profile it is assumed that all angle values will return the same depth based on the radius (that is the distance from the center of the rotation).  Similarly a rectangular surface will return a single depth value, based on x, for all y values if that surface has only one profile. The default assumption is for a rotational surface.

Only the depths of  a few key points on the surface need be specified. The depths of any other point is calculated by interpolating values from the nearest two or four points to that which is required. For example assume we had a surface with a single profile for angle zero degrees that gave depth values every 10mm between 0 and 100mm.  In this case the depth at radius 25mm  and any angle would be the average of the depths at 20mm and 30mm. If we added another profiles  at say at 90  and 180 degrees angle specified at every 20mm between 0 and 100mm. Then the depth at radius 25mm for any angle between 0 and 90 degrees would be calculated by averaging the four values at  zero degrees 20mm, zero degrees 30mm, 90 degrees 20mm and 90 degrees 40mm.

Therefore a surface is just a linear approximation to the real thing and the more points defined the better the approximation.
