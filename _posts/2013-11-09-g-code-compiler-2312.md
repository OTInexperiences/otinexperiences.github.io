There is now available a compiler that converts programs written in a C type syntax to gcode. See <a href="http://www.vagrearg.org/content/gcmc  ">here</a> for more information. To test it I have re-written my wheels program (see <a href="http://www.ab48.uk/otblog/wp-content/uploads/2013/11/wheelsgcmc.txt">wheelsgcmc</a>) and it seems to work well.  I hope to use the compiler to put a collection of gcode programs to generate paths up on the site.
