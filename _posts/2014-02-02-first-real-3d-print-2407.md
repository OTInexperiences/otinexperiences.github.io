Its not much but designed and printed a part to make a T joint in 20x20 aluminium section.

<figure class="wp-recovered-caption">
<a href="{{ '/assets/recovered/f349ccad09-profile-connector2.3.png' | relative_url }}"><img alt="profile-connector2.3" class="size-full wp-image-2406" height="594" src="{{ '/assets/recovered/f349ccad09-profile-connector2.3.png' | relative_url }}" width="780"/></a>
<figcaption>As designed in DesignSpark Mechanical</figcaption>
</figure>
<p style="text-align: left;">I first created the part in <a href="http://www.designspark.com/eng/page/mechanical">DesignSpark Mechanical</a> which is a free 3D CAD package from RS components. Then the part was exported in STL format.</p>
<p style="text-align: left;">The STL file was opened in a program called <a href="http://slic3r.org/">slic3R</a> which was used to create a gcode file to control the printer.</p>
<p style="text-align: left;">The printer was set up using a program called <a href="http://replicatorwarehouse.com/pronterface/">pronterface</a>, which has the facility to load in the gcode file and send it to the printer.</p>
