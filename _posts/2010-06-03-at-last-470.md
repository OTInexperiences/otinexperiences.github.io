Why does everything take at least three times longer than you anticipate?  Anyway at last I am in a position to be able to use rose mark2. In fact I cut a pattern on a bowl with it this afternoon. I used my proxxon mill head and a 2.5mm cutter. I intend to fill the resulting path with coloured resin and finish off tomorrow if possible.

My software will save the g-code for all paths in a single file by default. I have found this to be a problem and ended up by saving each path in its own individual file. Then I ran each file sequentially. The reason I did it that way was because I found that the proxxon motor tends to run hot after completing a single path when running at max revs. So I just ran a path then waited a bit to allow the motor to cool down before cutting the next one. I cut 1mm per pass for three passes giving a 3mm depth to fill with coloured resin.

Setting up was a manual operation that didn't require accurate centering of the cutter at the bowls centre. From the bowl I had measured (yes you still need to use a ruler even if it is cnc) that  my pattern lay between 80 to 120 mm. I knew that the maximum radius to be cut was 120mm so I first set the  x axis  zero point (x corresponds to the radius)  so that I knew that at 120mm I would have plenty of room and that my machine  would not be hitting the end of its travel.

I then set my mill head position roughly and bolted it down then I used emc's controls to manually moved the bowl position so that the cutter was over the position I wanted the outermost  most point to be at  (On this engine the cutter is stationary and the work moves) .  Then I used emc's "touch off" facility to adjust the machines  origin so that the current position became 120mm.

After measuring the distance from the cutter to the edge of the bowl  with my ruler I used  emc's manual mode  to move the work to the innermost radius value  80 mm and  measured the distance from the cutter to the innermost edge.  I wanted the  two measurements to be the same so that the pattern was correctly centered between the outermost and innermost edges of my bowl.    So I again manually moved the work and used  "touch off " to set the correct axis value. Repeated this until I was satisfied that my pattern was centered accurately by eye for wood turning purposes, not down to 0.001 mm as an engineer would.  I should say for those who do not know emc,  In manual mode you can select the distance to move  each time you press a button from  either 5, 1, .1 or .001 mm and indeed you can specify these distances in the emc initialization file.

If you look at the first image you will notice there is a polished band around the centre of the bowl but the rest isn't polished.  Well I had polished the top before I started cutting the paths the first time using the file with all the paths in it, halted the program at a point when I thought the motor was too hot and made a mess of re-starting that was when I decided to cut each path separately. Fortunately I had only cut 1mm so I skimmed off that first attempt and had another go. However at the top of the bowl you can see partly where I went wrong, there is a small hole where the cutter plunged in too deeply. I need to fill that with spare wood dust and super-glue before I polish and hope that it becomes relatively unnoticeable.
