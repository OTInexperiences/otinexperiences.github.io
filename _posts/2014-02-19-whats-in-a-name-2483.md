When starting to build my new engine, I wanted to make it modular. I am realising that it is turning into a truly multi purpose piece of equipment. So I need to opt for a name preferably one with a catchy acronym. Its modular, desktop sized, extendable, manual or computer controlled, multi-purposed machine for ornamental turning. Anyone come up with a catch acronym?

The purposes are going to be (with the addition / reallocation of parts )
<ol>
<li>A rose engine with lateral and pumping movement.</li>
<li>A straight line engine.</li>
<li>A geometric pattern generator (aka geometric chuck).</li>
<li>A standard small mill using a cutting head.</li>
<li>A 3D printer using a extruder head.</li>
</ol>
